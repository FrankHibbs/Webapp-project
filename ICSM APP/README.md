# Gameplan

**Created by Morgan Bender**

Gameplan turns an athlete’s goals into a focused, sport-specific training plan. Athletes choose their sport, experience level, goal, plan length, and weekly availability to get an organized practice calendar with detailed sessions, drills, and recommended durations. The dashboard makes it easy to review the week, open a daily workout, and track completed sessions.

Built from the ICSM App Project brief. The app focuses on personalized weekly practice, long-term training organization, and clear daily workout details. Wearable integrations and social networking are outside the project scope.

## Run locally

Open `index.html` in a modern web browser. No build step or dependencies are required.
